# Talent Nexus Screenshots

Place the following screenshots from your live app in this folder.

The carousel will load them automatically — no code changes needed.

## Required Files

| File | What to capture |
|---|---|
| `recruiter-dashboard.png` | The recruiter's main dashboard showing job postings |
| `student-portal.png` | Student's job listing and application page |
| `admin-panel.png` | Admin's user/company management interface |
| `auth-flow.png` | Login page or the role selection / RBAC screen |

## Recommended
- Capture in browser at 1400×900 or larger
- Use dark mode if your app supports it
- Make sure there is real data visible (not empty state)
