# Home Town Hub Screenshots

Place the following screenshots from your live app in this folder.

## Required Files

| File | What to capture |
|---|---|
| `directory.png` | Main business listing directory page |
| `events.png` | Community events board |
| `search.png` | Category search / filter in action |
| `owner-portal.png` | Business registration or owner management form |

## Recommended
- Capture in browser at 1400×900 or larger
- Make sure there is real data visible (not empty state)
