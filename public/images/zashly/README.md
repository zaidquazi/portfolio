# Zashly Screenshots

Place the following screenshots from your live app in this folder.

## Required Files

| File | What to capture |
|---|---|
| `group-chat.png` | Group channel or DM chat thread with messages visible |
| `video-call.png` | Active video call screen (can be a self-call for screenshot) |
| `stories.png` | Stories feed showing uploaded story rings |
| `presence.png` | Online presence / friends list showing active users |

## Recommended
- Capture in browser at 1400×900 or larger
- Use dark mode if your app supports it  
- Make sure there is real data visible (not empty state)
